## <img src="assets/minopal.png" height="28" alt="Minopal icon"> In production: Minopal (a table timer for restaurant floor staff)

[Repository](https://github.com/kotani-takumi0/table_check_app)

Floor staff at the Mexican izakaya where I work part-time use this app on the restaurant's iPads and their phones during service.

- **Problem solved**: Staff used to keep track in their heads of when to serve the appetizer, when to call last order, and when a table's time was up. In Minopal, tapping an empty table to seat guests starts a timer for that table, and tables that need attention stand out by color
- **Usage**: The first version went into the restaurant on September 25, 2026, and it is still used at every service. Several devices share the same screen
- **My role**: Everything on my own — talking with staff, UI design, implementation, Firebase setup (Firestore, Hosting, Auth), security rules, and releases
- **How I built it**: Using Claude Code, Codex, and Grok Bot, I merged 105 PRs and shipped 21 releases in 3 weeks, improving the app while the restaurant used it. For example:
  - Tapping twice in a hurry advances only one step, and "Undo" is available for 6 seconds
  - When a new version ships, devices that are left open update to it automatically
  - Staff can send feedback directly from the app
- **What staff said**: "Managing last orders got easier" and "When I send feedback, it gets fixed right away, which I appreciate"
- **Tech**: TypeScript, React, Vite, Firebase, Expo (React Native, iOS app), Vitest
